# Modern Dark 무녹색 팔레트 디자인

## 목적

현재 레이아웃, 정보 밀도, 타이포그래피, 아이콘과 동작은 유지한다. 녹색·민트·청록색에 치우친 표현만 제거하고, 상태를 인디고·바이올렛·시안·앰버·코랄·슬레이트로 구분하는 Modern Dark 테마로 교체한다.

## 성공 기준

- UI에서 녹색과 민트 계열 토큰 및 하드코딩 색상이 남지 않는다.
- Running, Complete, Connected가 서로 다른 색상 역할을 사용한다.
- 상태는 색상만이 아니라 기존 텍스트와 Phosphor 아이콘으로도 구분된다.
- 레이아웃, 콘텐츠, 데이터 흐름, 애니메이션과 반응형 동작은 바꾸지 않는다.
- 기존 단위 테스트, Sites 테스트와 프로덕션 빌드가 통과한다.

## 검토한 접근법

1. 기존 `--mint` 값만 시안으로 변경한다.
   - 변경은 가장 작지만 토큰 이름과 의미가 어긋나고, 하드코딩된 청록색 표면이 남는다.
2. 컴포넌트마다 개별 색상을 직접 교체한다.
   - 세밀하지만 중복이 늘고 이후 색상 일관성을 유지하기 어렵다.
3. 의미 기반 토큰과 상태 매핑을 함께 교체한다. **채택**
   - 기존 CSS 구조를 유지하면서 `--mint`를 제거하고 상태별 역할을 명확히 분리할 수 있다.

## 상태 매핑

- Running과 활성 작업 강조는 인디고를 사용한다.
- Complete와 Planning은 바이올렛을 사용하되 아이콘과 라벨로 의미를 구분한다.
- Connected와 Live feed만 시안 블루를 사용한다.
- Waiting과 Syncing은 앰버를 사용한다.
- Needs input, Blocked, Failed는 코랄을 사용한다.
- Idle, Paused, Cancelled, Stopped는 슬레이트를 사용한다.
- 선택된 세션 레일, 포커스 링과 주요 강조는 인디고를 유지한다.

## 구현 범위

- `src/styles.css`의 루트 토큰과 녹색·민트·청록 계열 하드코딩 값을 교체한다.
- 필요할 때만 `src/App.jsx`의 인라인 색상을 의미 토큰과 일치시킨다.
- 색상 교체 외 구조·컴포넌트·카피·상태 로직은 변경하지 않는다.
- 프로젝트의 영구 디자인 결정으로 AGENTS.md에 무녹색 상태 팔레트를 기록한다.

## 검증

- `rg`로 `mint`, 기존 RGB `73 213 173`, 녹색 계열 하드코딩 값이 남지 않았는지 확인한다.
- `npm test`, `npm run build`, `npm run test:sites`를 실행한다.
- 헤드리스 브라우저 캡처로 글로벌 활동 보드와 선택 세션 상세를 확인한다.
- 작은 보조 텍스트와 상태 배지의 대비, 포커스 표시, 색상 외 아이콘·라벨 구분을 확인한다.
