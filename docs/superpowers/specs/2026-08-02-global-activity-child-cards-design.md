# Global Activity 자식 에이전트 카드 디자인

## 목표

- Global Activity의 네 상태 레인에 루트 세션뿐 아니라 자식 에이전트도 각각 별도 카드로 표시한다.
- 자식 카드가 어느 작업 환경에 속하는지 부모 정보로 식별하면서도 `Child` 태그와 자식 고유 정보로 루트 카드와 구분한다.
- 자식 카드를 클릭하면 루트 상세로 전환하지 않고 기존 Child Agent 상세 다이얼로그를 바로 연다.

## 데이터 구성과 레인 배치

`GlobalActivityBoard`가 받은 루트 세션마다 루트 카드 항목 하나와 각 `children`의 자식 카드 항목을 만든다. 자식 카드 항목에는 부모의 `projectName`, `gitBranch`, `session`을 화면 표시용으로 복사하고, 상태·현재 작업·최근 활동·세션 시간·닉네임·모델은 자식 자신의 값을 사용한다. 스냅샷 형식과 수집 로직은 변경하지 않는다.

루트와 자식 항목은 기존 `getActivityBoardLanes`에 함께 전달한다. 따라서 각 자식은 자신의 상태에 따라 Active, Waiting, Inactive, Ended 중 하나에 정확히 한 번 들어가며, 레인 안에서는 루트와 자식을 구분하지 않고 기존 최근 활동 정렬을 따른다. 레인 카운트는 표시된 루트 카드와 자식 카드의 합계다.

상단 세션 목록은 계속 루트 세션만 표시하고, 선택된 루트 상세의 Child Agents 목록도 그대로 유지한다.

## 카드 표시

루트와 자식은 하나로 합치지 않고 각각 독립된 카드를 사용한다. 기존 글로벌 카드의 상태 배지, 현재 작업, 최근 활동, 상대 시각, 세션 시간을 재사용한다.

자식 카드는 다음 차이를 가진다.

- 프로젝트명, 브랜치명, 세션명: 부모 루트 세션의 값
- 현재 작업, 최근 활동, 상태, 세션 시간: 자식 자신의 값
- 우상단: Complete 상태와 구분되는 시안 계열의 평면형 `Child` 태그
- 하단 우측: `닉네임 / 모델명` 형식의 한 줄 정보. 카드 폭이 부족하면 말줄임 처리
- 닉네임 누락 시 기존 규칙대로 스레드 ID 앞 8자를 사용하고, 모델 누락 시 `Model unavailable`을 표시

새 색상 토큰, 장식 그라데이션, 발광 효과는 추가하지 않는다. 루트 카드의 내용과 상호작용은 변경하지 않는다.

## 상호작용과 접근성

루트 카드는 기존처럼 세션 상세를 연다. 자식 카드는 `aria-haspopup="dialog"`와 Child Agent 다이얼로그 연결 정보를 제공하고, 클릭 시 기존 `ChildAgentDialog`를 Global Activity 위에 바로 연다. 이때 부모 루트를 선택하거나 오른쪽 영역을 루트 상세로 전환하지 않는다.

선택한 자식이 현재 스냅샷에 없으면 다이얼로그를 렌더링하지 않는다. 별도 상세 화면이나 새로운 전역 상태 모델은 만들지 않고 기존 자식 선택 상태와 다이얼로그를 재사용한다.

글로벌 카드 이동은 기존 고유 ID 기반 동작을 그대로 사용한다. 자식의 실제 상태 또는 최근 활동 시각이 바뀌어 정렬 위치나 레인이 달라질 때만 다음 적용 스냅샷에서 이동한다.

## 변경 범위

- `src/App.jsx`: 보드용 루트·자식 항목 구성, 자식 카드 변형, 다이얼로그 연결
- `src/styles.css`: `Child` 태그와 자식 카드 하단 정보 배치
- 관련 렌더링·레이아웃 계약 테스트
- `AGENTS.md`: Global Activity에 자식 카드도 표시한다는 제품 결정

`monitor/`의 스냅샷 수집 코드, 상단 루트 세션 목록, 선택된 루트 상세 구조, 4레인 상태 매핑은 변경하지 않는다.

## 검증 기준

- 루트 1개와 자식 2개가 있으면 Global Activity에 서로 다른 카드 3개가 표시된다.
- 각 자식 카드는 자신의 상태 레인에 정확히 한 번 들어가고 레인 카운트에 포함된다.
- 자식 카드에 부모의 프로젝트명·브랜치명·세션명과 자식의 `Child` 태그·닉네임·모델명이 표시된다.
- `Child` 태그는 Complete와 다른 시안 색상으로 카드 우상단에 표시된다.
- 닉네임·모델명은 하단 우측에서 줄바꿈 없이 한 줄로 표시되고, 폭이 부족하면 말줄임 처리된다.
- 자식 카드 클릭은 루트 상세를 열지 않고 기존 Child Agent 상세 다이얼로그를 연다.
- 루트 카드, 상단 루트 세션 목록, 선택된 루트 상세의 기존 동작은 유지된다.
- 관련 단위·렌더링·레이아웃 테스트와 전체 테스트, `npm run build`, `npm run test:sites`가 통과한다.
