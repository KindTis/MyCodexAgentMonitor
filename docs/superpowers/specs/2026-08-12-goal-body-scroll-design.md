# Goal 본문 내부 스크롤 설계

## 목표

선택한 루트 세션의 Goal 문자열이 길어져도 Goal 카드의 할당 높이 안에서 전체 내용을 확인할 수 있게 한다. Goal 내용 때문에 같은 열의 Recent activity와 Child agents 영역이 밀리거나 축소되어서는 안 된다.

## 범위

- 데스크톱 상세 2열의 Goal 25% / Recent activity 40% / Child agents 35% 비율을 유지한다.
- Goal 제목과 상태는 고정하고, 목표 내용·토큰·사용 시간만 내부에서 세로 스크롤한다.
- Child Agent 상세 대화상자의 기존 스크롤 동작은 변경하지 않는다.
- 새 컴포넌트나 공통 추상화는 추가하지 않는다.

## 구현

루트 세션 Goal 카드의 헤더 아래 콘텐츠를 하나의 본문 요소로 감싼다. 이 본문은 Recent messages 목록과 같은 방식으로 `min-height: 0`, `flex: 1`, `overflow-y: auto`를 사용한다. 바깥 Goal 카드는 기존 `overflow: hidden`을 유지하므로 긴 문자열이 CSS Grid 행의 높이를 늘리지 않는다.

기존 Goal의 목표 문장, 토큰, 사용 시간 스타일은 본문 요소 아래에서도 동일하게 적용한다. 데이터 구조와 렌더링 값은 바꾸지 않는다.

## 오류 처리

추가 오류 경로는 없다. Goal이 없을 때의 기존 빈 상태는 본문 스크롤 요소를 만들지 않고 현재 표시를 유지한다.

## 검증

- 레이아웃 계약 테스트에서 Goal 본문이 `min-height: 0`, `flex: 1`, `overflow-y: auto`를 갖는지 확인한다.
- Goal 카드의 `overflow: hidden`과 컨텍스트 열의 25% / 40% / 35% 비율이 유지되는지 확인한다.
- 전체 단위 테스트와 프로덕션 빌드를 실행한다.
- 코드 변경 뒤 `graphify update .`를 실행해 지식 그래프를 갱신한다.
